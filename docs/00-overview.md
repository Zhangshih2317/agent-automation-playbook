# Agent Automation Playbook — Overview

## The six themes

This playbook organizes 14 frontier projects along six core themes. Every
project you adopt should map to at least one (preferably more) of these.

| # | Theme | One-liner |
|---|---|---|
| 1 | **Self-evolution** | Agent learns new skills automatically |
| 2 | **Self-reflection** | Agent critiques its own output |
| 3 | **Group collaboration** | Multiple agents working a task |
| 4 | **Skill extraction & reuse** | Successful paths become Skills |
| 5 | **Long-term memory** | Remember across sessions |
| 6 | **Workflow generation** | Generate new workflows on demand |

## The 14 projects, organized

### Self-evolution
- **GenericAgent** (Tier 1) — auto-crystallizes repeated paths into Skills
- **ACE** (Tier 2) — Generator-Reflector-Curator with Playbook
- **EvoAgentX** (Tier 3) — TextGrad / AFlow evolution
- **SE-Agent** (Tier 3) — trajectory-level revise/reorganize/refine

### Self-reflection
- **Hindsight** (Tier 2) — TEMPR + CARA reflection over memory
- **ACE** (Tier 2) — Reflector role critiques every run
- **SE-Agent** (Tier 3) — refines trajectories from failures

### Group collaboration
- **CrewAI** (Tier 1) — role-driven crews with shared memory
- **MetaGPT** (Tier 2) — SOP-driven software company
- **AutoGen** (Tier 2) — event-driven multi-party chat
- **AutoAgent** (Tier 3) — NL-to-agent generation

### Skill extraction & reuse
- **GenericAgent** (Tier 1) — 5-layer memory, L3 = skills
- **UFO²** (Tier 1) — RAG over past executions (built-in)
- **ACE** (Tier 2) — Playbook bullets

### Long-term memory
- **Mem0** (Tier 1) — vector + (paid) graph, simple API
- **Hindsight** (Tier 2) — 4-way parallel retrieval, 91.4% LongMemEval

### Workflow generation
- **MetaGPT** (Tier 2) — SOP → full project
- **AutoAgent** (Tier 3) — NL → agent + workflow
- **EvoAgentX** (Tier 3) — DAG with evolutionary optimizer
- **LangGraph** (Tier 3) — explicit DAG + state mgmt + checkpoints

### Windows desktop automation (cross-cutting)
- **UFO²** (Tier 1) — Win32 + UIA + WinCOM hybrid
- **Windows-MCP** (Tier 3) — MCP server for any LLM client
- **Open Interpreter** (Tier 3) — NL → local code execution
